## 📜 Description
OpenSem simplifies your project setup. It offers a YAML-based configuration system that integrates smoothly with Claude Code. You can easily access pre-configured project templates, utilize automatic language server detection, manage memory templates, and configure workflows based on modes.

## 🛠️ Key Features
- **YAML-based Configuration:** Easily customize your projects using simple YAML files.
- **Automatic Language Server Detection:** OpenSem detects the language server for you, eliminating the need for manual configuration.
- **Memory Template Management:** Keep your workspace organized with memory templates that help in managing your project settings.
- **Mode-based Workflow Configuration:** Adapt your workflow to different coding modes for efficient project handling.
- **Pre-configured Project Templates:** Start strong with ready-to-use templates that meet your coding needs.
